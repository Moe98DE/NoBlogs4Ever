# Code of Conduct

## Our pledge

We want NoBlogs4Ever to be a welcoming project for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

* Be respectful and considerate, including when you disagree.
* Give and accept constructive feedback gracefully; focus on what is best for the project and its users.
* Assume good faith, and help newcomers.
* Respect people's privacy: never share someone else's personal information.

## Unacceptable behaviour

Harassment, insults or personal attacks; sexualised language or imagery; discriminatory jokes; trolling; threats; publishing others' private information; and any conduct that would be inappropriate in a professional setting.

## Scope and enforcement

This applies in all project spaces (issues, pull requests, discussions, chat) and when representing the project elsewhere. Report problems privately to the maintainers through the contact listed on the repository owner's GitHub profile, or by opening a private security advisory if no other channel is available. Maintainers will review reports promptly and confidentially and may warn, temporarily ban or permanently ban contributors who violate this code.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
