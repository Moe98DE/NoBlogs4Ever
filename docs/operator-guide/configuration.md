# Configuration reference

Configuration has three layers:

1. **`.env`** (or the file named by `NBE_ENV_FILE`) — plain settings, read by Docker Compose and passed to every container. Start from `.env.example`.
2. **`secrets/`** — one file per secret, mode `0600` in a `0700` directory, never committed. Mounted as Docker secrets.
3. **Network Admin → Platform policy** — a few policies operators can change at runtime; they override `.env` once saved.

## Secrets

| File | Used by | Notes |
|---|---|---|
| `db_password`, `db_root_password` | MariaDB, app, backup | Random, generated by `make init` |
| `wp_salt` | WordPress | All WordPress keys and salts are derived from it. Rotating it signs everyone out. |
| `admin_password` | `make bootstrap` | First operator account; change it after first sign-in |
| `smtp_password` | outgoing mail | Your provider's SMTP password (production) |
| `backup_password` | Restic | Encrypts backups. **Escrow it separately** — without it backups are unreadable. |
| `restic_backend.env` | Restic | Remote storage credentials, `KEY=value` lines (see [Backup and restore](backup-restore.md)) |
| `demo_password` | `make seed` | Development only |

`make init` / `./noblogs4ever setup` create missing secrets with 48 random bytes and never overwrite existing files.

## Environment variables

### Platform

| Variable | Default | Meaning |
|---|---|---|
| `PLATFORM_DOMAIN` | `lvh.me` | Base domain. Sites are `<slug>.<PLATFORM_DOMAIN>`. |
| `PLATFORM_SCHEME` | `http` | `https` in production (required). |
| `PLATFORM_PORT` | `8080` | Development port. Ignored in production. |
| `APP_ENV` | `development` | `production` enables HTTPS-only cookies, MFA enforcement for operators, refuses demo data and tests. |
| `NBE_APP_IMAGE` | `noblogs4ever:local` | Production: a registry reference pinned by `@sha256:` digest. |
| `BRAND_NAME` | `NoBlogs4Ever` | Shown in the dashboard and email sender name. |
| `SUPPORT_EMAIL`, `NBE_ADMIN_EMAIL` | — | Real addresses in production; operators receive approval requests at `NBE_ADMIN_EMAIL`. |
| `DEFAULT_THEME` | `twentytwentyfive` | Theme for new sites (must be curated). |
| `RESERVED_SLUGS` | — | Extra site names to refuse, comma-separated (built-in list in `Policy::RESERVED_SLUGS`). |

### Email

| Variable | Default | Meaning |
|---|---|---|
| `SMTP_HOST`, `SMTP_PORT` | `mail`, `1025` | Mailpit in development; your provider in production. |
| `SMTP_USER` | — | Enables SMTP authentication when set (password in `secrets/smtp_password`). |
| `SMTP_TLS` | — | `tls` (STARTTLS) or `ssl` in production. |
| `SMTP_FROM` | — | Sender address. |
| `SMTP_TEST_RECIPIENT` | — | Mailbox used by `make smtp-test`. |
| `MAIL_PER_HOUR` | `200` | Network-wide cap on outgoing mail, protecting your sender reputation. |

### Registration and accounts (also editable in Platform policy)

| Variable | Default | Meaning |
|---|---|---|
| `REGISTRATION_POLICY` | `invitation` | `invitation`, `approval`, `allowlist` or `unrestricted`. |
| `NBE_ACK_OPEN_REGISTRATION` | `no` | Must be `yes` for `unrestricted` to pass `make production-check`. |
| `REGISTRATION_ALLOWLIST` | — | Exact email domains for the `allowlist` policy. |
| `REGISTRATION_DENYLIST` | — | Domains always refused, including for invitations. |
| `MAX_SITES_PER_USER` | `3` | Sites one account may administer (operators exempt). |
| `REQUIRE_MFA_FOR_SITE_ADMINS` | `no` | Also require TOTP/security keys for site administrators. |
| `SESSION_HOURS` | `24` | Sign-in session lifetime. |

### Content and media

| Variable | Default | Meaning |
|---|---|---|
| `MAX_UPLOAD_MB` | `32` | Largest single upload (also limited by PHP's 256 MB). |
| `SITE_QUOTA_MB` | `1024` | Storage per new site. Change existing sites in Network Admin → Sites → Edit. |
| `ALLOWED_EXTENSIONS` | `jpg,jpeg,jpe,png,gif,webp,pdf,txt,mp3,mp4,ods,odt` | Subset of the safe types in `Media::SAFE_TYPES` (also avif, csv, m4a, ogg, wav, webm, m4v, odp, docx, xlsx, pptx, epub). SVG and HTML are never allowed. |
| `IMAGE_MAX_EDGE` | `2560` | Larger images get a scaled copy; the original is kept. |
| `EMBED_IFRAME_HOSTS` | — | HTTPS hosts allowed in `<iframe>` (e.g. `www.openstreetmap.org`, or `.example.org` for a domain and its subdomains). Allowed iframes are sandboxed. |
| `ALLOW_GRAVATAR` | `no` | `yes` lets readers' browsers load Gravatar avatars. |
| `ENABLE_EXPERIMENTAL_INTEGRATIONS` | `no` | `yes` offers Polylang and ActivityPub to site administrators. Must be `no` for `make production-check`. |

|---|---|---|

### Backups and storage

| Variable | Default | Meaning |
|---|---|---|
| `RESTIC_REPOSITORY` | `/repository` | `s3:…`, `b2:…`, `rest:…`, `azure:…` or a local path. |
| `BACKUP_REPOSITORY_PATH` | `./.runtime/backups` | Host directory for a local repository. |
| `RESTIC_BACKEND_ENV_FILE` | `secrets/restic_backend.env` | Remote credentials. |
| `RESTIC_AUTH_EXTERNAL_ACK` | `no` | `yes` when credentials come from workload identity instead of the file. |
| `BACKUP_REQUIRE_REMOTE` | `yes` in production checks | Require a remote repository. |
| `BACKUP_LOCAL_OFFHOST_ACK` | `no` | `yes` attests that a local repository is replicated off the host. |
| `BACKUP_RETENTION_DAYS` | `14` | Daily snapshots kept. |
| `BACKUP_MAX_AGE_HOURS` | `26` | Freshness threshold for monitoring. |
| `MIN_FREE_GB`, `STORAGE_CHECK_PATH` | `5`, `.` | Disk checks in `make production-check`. |

### Production-only

| Variable | Meaning |
|---|---|
| `TLS_DIRECTORY` | Absolute path containing `fullchain.pem` and `privkey.pem` for the base and wildcard name. |
| `TLS_MIN_VALID_DAYS` | Minimum remaining certificate validity accepted by `make production-check` (default 21). |
| `IMPORT_DIRECTORY` | Host directory mounted read-only at `/imports` for [large imports](migration.md). |

### Resource limits

`APP_MEMORY_LIMIT`, `APP_CPU_LIMIT`, `APP_PIDS_LIMIT`, `DB_MEMORY_LIMIT`, `DB_CPU_LIMIT`, `DB_PIDS_LIMIT`, `EDGE_*`, `BACKUP_*` override the container limits in `compose.yaml` (defaults: app 768 MB / 1.5 CPU, database 1 GB / 2 CPU).

## Runtime policy (Network Admin → Platform policy)

Operators can change registration policy, allow/deny lists, sites per person and the site-admin MFA requirement without a restart. Saved values are stored as network options (`nbe_registration_policy`, …) and take precedence over `.env`. To return to `.env` control, delete the option: `wp site option delete nbe_registration_policy`.
